git commit
Creates a commit containing the staged changes.
Example: git commit -m "Add Git Cheatsheet"
-m lets you provide the commit message directly.

git branch
Shows the branches in the repository.
git branch <branch-name> creates a new branch.
Example: git branch lesson2

git checkout
Switches to another branch.
Example: git checkout main
Example: git checkout lesson2

git pull
Downloads changes from a remote repository and integrates them into the current branch.
Example: git pull upstream main

git push
Uploads local commits to a remote repository.
Example: git push origin main
-u can set the upstream tracking branch when pushing a new branch.
Example: git push -u origin lesson2

git merge
Combines changes from another branch into the current branch.
Example: git merge <branch-name>

git rebase
Moves/reapplies commits on top of another branch.
Example: git rebase <branch-name>

git fetch
Downloads updates from a remote repository without merging them into the current branch.
Example: git fetch upstream main
